# 文档搜索索引 DocFinder v1.0

一款 Windows 10 便携版全文搜索索引工具，专为大容量硬盘文档检索设计。

即使硬盘不在线，也可通过已保存的索引文件搜索文档内容。

---

## 功能特性

- **多格式支持**：doc / docx / xls / xlsx / ppt / pptx / PDF（可选）
- **中文全文搜索**：SQLite FTS5 + jieba 分词，毫秒级响应
- **离线搜索**：索引保存为单个 `.db` 文件，硬盘不在也能搜索
- **离线预览**：双击搜索结果，弹出关键词命中段落 + 全文预览
- **多线程索引**：并行提取文档内容，速度快
- **增量更新**：只处理新增/修改的文件，跳过未变化的文件
- **便携版**：单个 exe，无需安装，双击即用

## 快速开始

### 方式一：直接下载 exe（推荐）

前往 [Releases](../../releases) 页面下载最新版 `DocFinder_v1.0.exe`，双击运行即可。

### 方式二：从源码打包

**前提**：已安装 Python 3.8+（安装时勾选 "Add Python to PATH"）

1. 下载或克隆本仓库
2. 双击运行 `一键打包exe.bat`
3. 等待 3~8 分钟，在 `dist\` 目录找到 `DocFinder_v1.0.exe`

## 使用方法

### 建立索引
1. 打开软件，点击菜单 **索引 → 新建索引**
2. 选择要索引的文件夹（支持整个硬盘）
3. 选择要索引的文件格式（默认勾选 Word/Excel/PPT）
4. 选择索引文件保存位置（生成 `.db` 文件）
5. 点击确定，等待索引完成

### 搜索文档
- 在搜索框输入关键词，按回车
- 左侧显示匹配文件列表
- 右侧显示关键词命中的上下文摘要

### 打开文件
- **双击**搜索结果：
  - 硬盘在线 → 直接打开文件
  - 硬盘离线 → 弹出离线预览窗口（关键词段落 + 查看全文）

### 加载已有索引
点击 **索引 → 加载索引**，选择之前保存的 `.db` 文件。

### 更新索引
点击 **索引 → 更新索引**（或按 F5），只处理变化的文件。

| 界面 | PyQt5 |
| 索引引擎 | SQLite FTS5 |

---

## 注意事项

- `.doc` / `.ppt` 老格式需要系统安装 LibreOffice 才能提取文字
- 扫描版 PDF 需要安装 Tesseract OCR 并在新建索引时勾选"启用 OCR"
- 打包时杀毒软件可能误报，属于正常现象，可暂时关闭后重试
